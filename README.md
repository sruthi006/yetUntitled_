# YET UNTITLED 🎥  
> A collaborative film-making platform for creators

YetUntitled is a web application built to help filmmakers and creators manage, showcase, and collaborate on film projects in a structured and modern way.

This project is part of my journey in learning and building real-world full-stack applications.

---

## 🔗 Live Preview

🌐 https://yetuntitled.vercel.app/

---

## 🧠 Problem It Solves

- Organizing film projects in one place
- Helping creators collaborate easily
- Providing a platform to showcase creative work
- Managing content in a structured way

---

## ✨ Key Highlights

- Clean and modern UI
- Project showcasing system
- Scalable structure for future features
- Built with real-world full-stack architecture
- Beginner-friendly but production-style structure

---

## 🛠️ Built With

- React.js (Frontend)
- Node.js & Express.js (Backend)
- MongoDB (Database)
- CSS / Tailwind CSS
- Deployed on Vercel
